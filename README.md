# Ubuntu Server Docker&Docker Compose Auto Install

우분투 서버에 도커&도커 컴포즈에 대한 자동 설치 스크립트 입니다.

### 가져오기
---
```bash
  git clone https://github.com/ghostlycn/ubuntu-docker-install.git
```

### 실행방법
---
```bash
  cd ubuntu-docker-install
  chmod +x install.sh
  ./install.sh
```
or
```bash
  cd ubuntu-docker-install
  bash install.sh
```
